# Wayanad Page CMS Quick Guide

## 🚀 Quick Start

1. **Access CMS**: Go to `yourdomain.com/admin`
2. **Navigate**: Click "Wayanad Page" in sidebar
3. **Edit**: Click "Wayanad Page Content"

## 📝 What You Can Edit

### SEO Settings
- **Page Title**: Browser tab title
- **Meta Description**: Search engine description
- **Keywords**: SEO keywords
- **Author**: Content author

### Hero Section
- **Background Image**: Main hero image
- **Hero Title**: Large page title

### Attractions (13 total)
- **Title**: Attraction name
- **Description**: Detailed info (supports markdown)
- **Image**: Attraction photo

### Page Content
- **Body**: Main page text (supports markdown)

## 🖼️ Image Guidelines

- **Hero Image**: 1920x1080px recommended
- **Attraction Images**: 16:9 aspect ratio
- **Format**: JPG, PNG, or WebP
- **Size**: Under 500KB per image

## ❓ FAQ Management

FAQs are managed separately:
1. Go to "FAQs" in sidebar
2. Click "Wayanad Page FAQs"
3. Add/edit/remove questions

## 💡 Tips

- **Save as Draft**: Test changes before publishing
- **Preview**: Always preview before publishing
- **Images**: Use descriptive filenames
- **Content**: Keep descriptions engaging but concise

## 🔧 Troubleshooting

**Images not showing?**
- Check file format (JPG, PNG, WebP)
- Ensure file size < 500KB
- Verify image dimensions

**Content not updating?**
- Click "Publish" after editing
- Clear browser cache
- Check for typos in markdown

**CMS not loading?**
- Check internet connection
- Try refreshing the page
- Contact admin if issues persist
